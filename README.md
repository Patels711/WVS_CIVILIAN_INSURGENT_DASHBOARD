# WVS Civilian Insurgent Dashboard

An interactive research dashboard for exploring survey responses related to gender attitudes, social norms, and demographic patterns among former FARC combatants. It compares selected findings with civilian World Values Survey data to support research exploration and presentation.

## Project Overview

This project visualizes survey data collected from former combatants and compares patterns with broader civilian responses from the World Values Survey. The dashboard is intended to help researchers, students, and presenters explore demographic patterns and question-level responses in an accessible format.

## Project Goals

- Explore gender attitude survey results
- Compare insurgent and civilian response patterns
- Provide accessible visual analysis
- Support research communication and presentation
- Highlight demographic and attitudinal differences

## Features

- Interactive dashboard interface
- Raw data exploration
- Chart comparison views
- Demographic comparison tools
- Streamlit-based web app
- Embedded project images and research context

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- Seaborn
- CSV data processing

## Requirements

- Python 3
- Required packages from `requirements.txt`
